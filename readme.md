# 🍽️ Restaurante Sabor & Arte

Landing Page responsiva desenvolvida para um restaurante fictício, com foco em **design moderno, semântica HTML, acessibilidade e experiência do usuário**.

O projeto apresenta informações sobre o restaurante, diferenciais, cardápio, história, localização e horários de atendimento.

---

## 📸 Sobre o projeto

O **Restaurante Sabor & Arte** foi desenvolvido como um projeto prático para aplicar conhecimentos de desenvolvimento Front-End, principalmente na construção de páginas:

* Semânticas
* Responsivas
* Acessíveis
* Organizadas
* Visualmente modernas

A página foi construída utilizando **HTML5 e CSS3**, sem a necessidade de JavaScript.

---

## 📱 Responsividade

O projeto foi desenvolvido seguindo uma abordagem **Mobile First**.

A interface se adapta a diferentes tamanhos de tela:

* 📱 Smartphones
* 📲 Tablets
* 💻 Desktops
* 🖥️ Telas maiores

Foram utilizadas **Media Queries** para adaptar os layouts de acordo com a largura disponível.

### Breakpoints utilizados

```text
Mobile
até 599px

Tablet
600px ou superior

Desktop
992px ou superior
```

## ♿ Acessibilidade

A acessibilidade foi considerada durante o desenvolvimento da página.

Entre os recursos utilizados estão:

* HTML semântico
* Textos alternativos nas imagens
* `aria-label`
* `aria-labelledby`
* `aria-hidden`
* Navegação semântica
* Elemento `<address>` para localização
* Estados de foco com `:focus-visible`
* Suporte para `prefers-reduced-motion`

Exemplo:

```html
<nav aria-label="Navegação principal">
```

E:

```html
<i class="fa-solid fa-utensils" aria-hidden="true"></i>
```

Esses recursos ajudam tecnologias assistivas, como leitores de tela, a interpretar melhor o conteúdo da página.

## 🧩 Seções da página

O projeto é dividido nas seguintes seções:

### 🏠 Hero

Apresenta o restaurante com uma imagem de destaque, título, descrição e botão para acessar o cardápio.

### 🌿 Diferenciais

Apresenta os principais diferenciais do restaurante:

* Ingredientes orgânicos
* Entrega rápida
* Chef renomado

### 🍝 Cardápio

Exibe os pratos disponíveis, incluindo:

* Massa Artesanal
* Bowl Sabor & Arte
* Filé Sabor & Arte
* Peixe Grelhado
* Hambúrguer Artesanal
* Delícia de Chocolate

### 📖 Nossa história

Apresenta a história e a proposta do Restaurante Sabor & Arte.

### 📍 Localização e horários

Exibe o endereço e os horários de funcionamento do restaurante.

### 🔗 Rodapé

Contém informações sobre direitos autorais e links para redes sociais.
